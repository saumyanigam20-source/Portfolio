## Project Overview

KlearNow is a logistics and customs compliance platform used by freight forwarders and import/export teams. The goal of this project was to redesign the KlearNow Tracking Tool interface to provide a faster, clearer, and more user-friendly way for users to check shipment statuses using different tracking number formats.

The redesign focused on improving usability, accessibility, and information clarity while maintaining alignment with KlearNow’s brand identity.

## Problem Statement

Users needed a simple and reliable way to track shipments across multiple formats (MBL, HAWB, Railbill, etc.). The existing experience lacked:

- Clear validation feedback
- Consistent layout for results
- Easy access to important compliance documents
- Optimised experience across devices

This caused confusion, slower task completion, and unnecessary support requests.

## Objectives

- Enable users to track shipments using multiple tracking number formats
- Reduce user errors through form validation and clear input guidance
- Present shipment statuses in a clean, scannable format
- Allow users to directly receive ABI documents via email
- Ensure the interface is responsive and accessible across all devices

## My Role

Product / UI-UX Designer. I was responsible for:

- UX flow design
- Wireframing and UI design
- Interaction design
- Accessibility and responsiveness considerations

## Design Process

### 1. Understanding user needs

Primary users included logistics coordinators, customs brokers, and operations teams.

Key needs: fast lookup, minimal input friction, clear compliance status indicators, and easy document access.

### 2. Information architecture & flow

The core user flow:

1. Enter tracking number
2. Complete captcha
3. Submit form
4. View shipment status
5. Optionally email ABI documents

This flow was designed to be linear, frictionless, and task-focused.

## Key Features Implemented

### 1. Multi-format tracking input

Users can input different types of tracking numbers:

- MBL / MBOL
- HAWB
- Railbill
- PARS / PAPS

This eliminated the need for separate tools or pages.

### 2. Form validation & captcha

- Real-time validation ensures required fields are filled
- Captcha prevents bot misuse and protects system integrity
- Clear error states guide users to fix issues instantly

### 3. Shipment status results layout

Results are displayed in a structured, easy-to-scan layout showing:

- Admissible Status
- Declaration Status
- PGA Status

Each status is visually separated for quick comprehension.

![Shipment status results](/images/case-studies/tracking-tool-redesign/results.png)

### 4. Email ABI documents

Users can email ABI documents directly from the tracking page, reducing manual steps and making compliance workflows more efficient.

### 5. Responsive & accessible UI

The interface was optimized for desktop, tablet, and mobile.

Accessibility considerations included clear contrast, legible typography, large tap targets, and logical tab flow.

## Visual Design Approach

- Clean, minimal UI
- Neutral color palette aligned with KlearNow branding
- Clear hierarchy using typography and spacing
- Status-driven design with visual grouping

The focus was on clarity over decoration — ensuring users get critical information as fast as possible.

## Impact & Outcomes

- Improved task completion speed for shipment tracking
- Reduced user errors due to validation and clearer inputs
- Better accessibility and mobile usability
- Streamlined document sharing via email
- More professional and trustworthy product experience

## Key Learnings

- In enterprise tools, clarity beats complexity
- Multi-format inputs should always include validation and guidance
- Status-heavy dashboards need strong visual hierarchy
- Small features (like email export) can significantly improve workflows
