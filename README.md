# Saumya Nigam — Portfolio

Minimal personal portfolio inspired by a clean single-page product-designer site structure.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

- Profile: `content/profile.md` and `src/lib/profile.ts`
- Case studies: `content/case-studies/*.md`
- Images: `public/images/case-studies/`
